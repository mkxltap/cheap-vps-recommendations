## 便宜 VPS 的“便宜”到底便宜在哪

便宜首先体现在首年报价，而真实成本由续费价、超售程度和流量额度三项决定。把这三项拆开看，很多看似 5 美元的机器实际不便宜。

**续费价**是最容易被忽略的一项。Hostinger 的 KVM 1 标价 4.99 美元/月（1 vCPU、4GB 内存、50GB NVMe），但这个价格要求签多年合约，续费价高于首价；Cloudways 起步 11 美元/月（DigitalOcean 1GB 方案，月付），年付折算 8.25 美元/月，官方明确不搞续费涨价。同样是“5 美元档”，三年下来的总支出可能差一倍。

**超售**决定你这台机器在高峰期还剩多少性能。OpenVZ 架构的低价机把宿主 CPU 和内存卖给远超物理容量的用户，标称的“独享核心”实际要跟几百个邻居抢；KVM 架构的隔离更接近真实独占。挑便宜机器时，架构比核数更该先看。

**流量额度**的差异也很实在。CloudCone 那台 31.25 美元/年的机器给到每月 4TB、1Gbps 端口；HostDare 的 34.99 美元/年方案是 4000GB + 4000GB、500Mbps 公网端口。看起来都是“几千 GB”，但端口速率差一倍，跑下载或视频中转时体验完全不同。

## 配置分界线：1 核 1G、2 核 2G、4GB 以上各干什么

1 核 1GB 只够静态站、反向代理、监控探针和轻量脚本；WordPress 加 WooCommerce 加一个不空闲的后台，至少需要 4GB 内存，低于这个数会频繁用 swap，手感比共享主机还差。

具体分档：

- **1 核 / 512MB–1GB**：纯静态页、单站点反代、定时任务、学习和练手。装带数据库的动态站会立刻吃紧。
- **2 核 / 2GB**：个人博客、低流量 API、小型论坛、轻量 Docker 一两个容器。这一档是年付 30 美元区间的主力，也是绝大多数个人站的实际需求。
- **4GB 及以上**：WooCommerce、多站点、需要跑 MySQL + Redis + 应用服务的情况。月付 5 美元档和 4GB 独享内存的年付机型都在这里。

选配置时容易犯的错是“按峰值买”。一个日访问几百 PV 的站点，2 核 2GB 完全够用，多买的核数一年也用不上几次。反过来，最不该省的是内存，CPU 吃紧还能等，内存吃紧直接 OOM。

## 机房位置比配置更能决定体验

因为延迟由物理距离决定，配置只能决定服务器处理请求有多快。同样一台 2 核 2GB，放在离访客 500 公里的机房和放在 12000 公里外，体验是两个产品。

选机房时按这个顺序判断：访客在哪 → 就近选区域 → 再看该区域有没有你要的套餐。香港、东京、新加坡这几个点对东亚和东南亚访客友好；洛杉矶对美国西海岸和部分亚洲线路都不差；欧洲业务放德国、英国、保加利亚更合适。

还有一个实用技巧：不确定就先用月付或按小时计费的方案开一台，从目标地区 ping 一下、跑一次真实页面加载，再决定要不要转成年付。年付省下的钱，抵不上选错机房后几个月的折腾。

## 下单前要核对的五件事

第一，确认虚拟化架构是 KVM。OpenVZ 类方案在低价段很常见，超售严重，标称的独享资源要跟大量邻居争抢。

第二，把续费价和计费周期一起看。首年 4.99 美元/月和三年平均 4.99 美元/月是两回事，Hostinger 那类低价通常绑定长约，Cloudways 那类则是明确不涨价的月付。

第三，算清备份成本。DigitalOcean 的定时备份按 Droplet 价格的 20% 收费，Hetzner 的快照是 €0.012/GB/月并自动保留 7 份每日快照，Vultr 首个快照免费。备份不是可选项，把它算进总价再比。

第四，确认流量是单向还是双向计费、超了之后是限速还是加钱。年付小厂的套餐大多写明月流量，超出部分的处理方式各家不同。

第五，正式跑业务前先建一个非 root 的 SSH 用户并改成密钥登录。默认的 root + 密码组合暴露在公网上，几分钟内就会开始被暴力尝试。

## 常见问题

**便宜 VPS 能跑 WordPress 吗？** 能，但要 2GB 内存起步。1GB 的机器装完 WordPress 加几个插件后基本没有余量，后台操作会明显卡顿。

**年付和月付哪个更划算？** 单价上年付通常低 30%–50%，但只在你已经确认机房延迟、配置够用、厂商稳定的前提下才划算。第一次用某家，先月付跑两周更稳。

**低价小厂会不会突然停服？** 有这个风险，所以备份要放在服务商之外。数据库每天导出一份到对象存储或本地，成本几乎为零，能避免最坏情况。

**国内访问海外 VPS 很慢，有解吗？** 换 CN2 GIA 一类优化线路能改善但价格更高，或者直接把站点放到国内节点。前者是在为线路付溢价，后者是消除距离，取舍看预算和访客分布。

**需要额外买 IPv6 吗？** 不少套餐已经附带 /64 IPv6，AlphaVPS、HostDare 的方案都包含；如果你的访客以移动网络为主，IPv6 值得保留。
